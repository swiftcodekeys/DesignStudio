## Project Goals

- Keep the existing 4-tab exploratory Design Studio for browsing, SEO landing pages, and inspiration.
- Build a cleaner guided quote flow for serious buyers.
- Do not force all users through the gate configurator.
- Preserve all design selections from the visual tool and carry them into the quote flow.
- Save a design snapshot image and carry it into the quote flow.
- Reduce re-entry friction: if a user already selected style, color, height, circles, finials, puppy picket, etc., do not ask for them again unless they explicitly edit them.
- Make the quote easier to understand by separating:
  1. what the user designed,
  2. what was measured,
  3. what the system auto-filled,
  4. what Grandview will review before production.

## Important Product Rules

- Gates are a separate product family with Walk Gates, Drive Gates, Estate Gates, and Cantilever Gates.
- Walk and Drive gates can be part of the main quote flow.
- Estate and Cantilever gates must be routed to custom review.
- Do not ask "Do you need gates?" early in the flow as if all gate types are equally configurable.
- Instead, treat the gate-offerings experience as optional exploration.
- Manual gate entry must be supported in the main quote flow.

## Measurement / Layout Rules

- Users should be able to either:
  - enter an address and build from front yard or backyard, or
  - skip and enter linear footage manually.
- The Draw Layout page must support:
  - New Line
  - Add Opening
  - Add Gate Manually
  - Undo
  - Finish Segment
- Right-click while drawing should remove the last point.
- Clarifying questions should happen on or directly around the layout step.

## Rackability Rules

- Rackability is not a whole-yard toggle.
- Rackability is segment-based / per-run based on grade change per 6' panel.
- Post upcharges apply to affected posts only.
- Privacy panels cannot rack.
- Racked walk gates are straight-top only.

## Pool Logic

- If the user starts with Backyard, ask whether any part of the fence acts as a pool barrier.
- Do not hard-block users from other styles.
- Keep all styles visible, but label supported pool-safe configurations versus review-required configurations.
- Final pool review still happens before production.
- Pool-compliant styles: Haven (UAB-200), Horizon flush (UAF-200), Vanguard flush (UAF-250). NO spear-top styles.
- BOCA requirements: 48"+ height, 45"+ between rails, <4" picket spacing, <4" bottom clearance, self-closing/self-latching gates opening outward, latch 54"+ above ground.

## Quote Behavior

- "Get Quote" should go directly into QuoteBuilder, not an intermediate quote modal/contact layer. (DONE in this session)
- ContactPopup should remain only for general contact/support flows.
- Final pricing shown to users should use an estimated range (~$1,500 spread) when real uncertainty remains around post specs, rackability, or shipping.
- Final quote page must include trust language that Grandview reviews every order before production.
- Both the customer AND sales@grandviewfence.com should receive the quote.
